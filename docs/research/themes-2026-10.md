# 导出四主题「结构级差异化」设计规范（R1 · 2026-10-10）

> 用途：导出主题重构的实现依据（第 ③ 步）。
> 基准：1em = 10.5pt × fontScale ≈ 3.70mm（100%）；A5 默认边距（14/12）内容区 124×182mm。

## 0. 结论

1. 趋同属实且可量化：四主题同骨架，差异只有装饰线/词头字号/间距/标签圆角。
2. **保留 4 个，重定义为骨架**：经典→**辞书体**、极简→**瑞士极简**、手账→**笔记手账**、紧凑→退役为「密度参数档」；主题位由**闪卡**接替。
3. 切换主题写入一组**结构默认值**（栏数/边距/行高/字体/字号/间距/分页模式/网格），用户仍可覆盖。
4. 选择器改 2×2 **骨架缩略卡** + 结构签名。

## 1. 现状诊断

- 四主题同构：header 块 + section 块 + 相同 gap；硬尺寸差仅 1.6/2.4mm 间距与 ±0.1em 字级。
- 色彩承载主要区分度 → 感知为"换色"。
- 网格 gap 硬编码 8px（`PrintDocument.tsx:139`），主题无法改变卡片节奏。

## 2. 四个骨架 spec（实现清单）

### 2.1 辞书体 Dictionary（原经典）
- 参考：OED 条目结构、朗文 LDOCE（音节点、义项编号、signpost）、小型大写词典分区。
- 默认：衬线；fontScale 95%；lineHeight 1.45；entryGap 4mm；节间距 1.6mm；分页 `align`；内容宽 ≥165mm → 2 栏（gap 8mm）。
- **义项悬挂缩进**：义项 `display:grid; grid-template-columns: 1.5em 1fr`；编号列 0.9em/700/accent/tabular；其余全部第 2 列（真悬挂）。
- 例句：英 0.95em；中 0.9em/`--wv-soft`；例句组左竖线 0.12em（`--wv-line` 70%）。
- **细密分隔**：节间 `border-top:1px color-mix(line 55%)`，上下 0.4em；词头主分线 1px `--wv-line` 50%。
- **行内标签（run-in）**：短字段（音标/词族/搭配/联想）标签 0.68em/700/字距 0.06em + 0.5em 空距接值。
- 「续」0.62em soft 小型大写（CJK 回退加粗+字距）。
- 排印比例：词头 1.42 : 正文 1 : 标签 0.68 : 义项号 0.9；数字全部 tabular。
- 色彩：accent=义项/词条编号、词性文字（**禁底色 chip**）；line=分隔/例句竖线；soft=音标/译文/词源。
- 分页：悬挂栅格必须**自包含在每个义项单元内**（不得依赖前一单元状态）；atomicMax 建议 30%。
- 校准：细线在矢量打印 vs html-to-image 的显隐；85–130% 字号长词溢出（overflow-wrap）；基线。

### 2.2 瑞士极简 Swiss（原极简）
- 参考：国际主义风格（非对称/网格/无衬线/左齐右不齐）、Müller-Brockmann、Vignelli Canon。
- 默认：无衬线；100%；lineHeight **1.8**；entryGap 10mm；节间距 3.2mm；边距 16/15；1 栏；**continuous**。
- **无标签**（默认关）；缩进阶梯 L0→L3（0/1.35em/2.7em）；义项号 0.72em soft 悬挂，内容缩进 1.35em。
- 分隔只允许 1 条（词头下 1px line 40% 或没有）；chips → 纯文本 0.9em soft、「·」分隔。
- 词头 1.32em/600/字距 −0.01em；meta 0.62–0.72em；Latin meta 大写+0.12em。
- 色彩：accent ≤5% 墨量（编号）；line=唯一分隔线；soft=meta/译文。禁止 color-mix 填充。
- 分页：关标签后续块需 0.62em soft 小写短语或短标题 [产品决策]。
- 校准：浅灰 tone 打印损耗（可能需加深 10–15%）。

### 2.3 笔记手账 Notebook（原手账）
- 参考：ほぼ日手帳（3.7mm 方眼）、国誉自我手帐、康奈尔三区、错题本要素。
- 默认：tone **cream**；边距 16/15；100%；lineHeight **1.7**；1 栏；entryGap 8mm；节间距 2.8mm。
- **横线纸底**：内容区 `repeating-linear-gradient`，pitch=1.7em，线色 line 55%；可选左竖线。**不进入测量层**。
- **胶带标签**：radius 0.15em；`rotate(-1.2deg)`（不参与测量）；底色 accent 14%；文字 0.68em/650。
- 词头 1.55em/650，下无线条，0.45em 空距。
- **笔记带（新块）**：cue 列 30% + 书写区 3 行实线 + CSS 方框勾选（不用 Unicode ☐）；`splittable:false` 且需 **glueWithPrev**（paginate 新增 ~10 行）；页面 2 栏时降级单列。
- 正文行高与横线同源（1.7）；空字段书写线 1.9em → 1.7em。
- 色彩：accent=胶带/竖线 30%；line=横线/书写线；soft=cue/日期/页脚。
- 校准：像素取整基线对齐（穿线压到 45–55% 呈肌理）；PNG 体积。

### 2.4 闪卡 Flashcard（接替紧凑）
- 参考：Quizlet 打印、Anki 字段模板、裁切标记/出血、riso 单色。
- **主用法=网格**：A5 2×3 卡/页；A4 3×4；grid gap **10mm**（改为参数）；边距 16mm；110%；1.55。
- 卡：radius 0.9em；1px line 边框；内边距 0.75em；词头 1.28em/650 + 2px accent 下划线（1.6em）；内容=词头+≤2 字段。
- **剪裁辅助线**：每卡四角外侧 1.5mm 处 2mm 直角短线（soft 60%），落在 10mm 缝内（距纸边 ≥16mm）；绝对定位实现、不参与测量；**wrapper 必须在 FlashcardCell 外层**（cell 有 overflow-hidden 会裁掉）。
- 流式模式（次要）：字段块级独立小卡（边框/radius 0.6em/padding .45em .6em/间距 2.2mm）。
- **无法真出血**（@page margin:0 + 纸张实尺寸 + overflow hidden）：剪裁线一律内缩。
- 色彩：accent=下划线/编号（单色小物感）；line=卡框；soft=剪裁线/meta。避免大色块。
- 校准：html-to-image 对绝对定位短线渲染；A5 内容溢出率；打印机不可打印区。

## 3. 交叉评审

- 差异矩阵：每对主题 ≥3 个结构轴硬差异（栏数/行高/标签/义项语法/分隔/底纹边框/留白/字体）→ 保留 4。
- 「紧凑」退役：下沉为密度参数档（fontScale 85–95% + 紧凑边距 + 1.6mm 间距）挂到辞书体。
- 最大风险对：辞书体 vs 瑞士（对策：主题写入结构默认值 + UI 明示已应用参数；首区分点=标签开/关＋A4 默认栏数）。
- 若必须收敛为 3：不建议（丢失网格留白价值；闪卡与 grid 耦合可接受）。

## 4. 主题缩略卡

- 2×2 缩略卡（72×96px，role=radio，选中 1.5px accent 描边）：抽象骨架图 + 名称 + 结构签名。
  - 辞书体："悬挂缩进 · 密排 · 细线"；瑞士："网格 · 无标签 · 留白"；手账："横线纸 · 书写区 · 胶带标"；闪卡："独立卡框 · 剪裁线 · 大留白"。
- 缩略图固定灰阶 + 少量 accent 点（避免回到"换色"认知）；二期可 hover 显示真实组件微缩。
- 切换主题显示「已应用结构默认值」提示 + 「保持我的版式参数」开关。

## 5. 实测校准清单（12 项，分矢量打印/图像导出两批）
