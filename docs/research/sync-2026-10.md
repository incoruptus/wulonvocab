# 跨端同步：研究与实施计划（R5 · 2026-10-10 实测）

> 结论先行：**Gist = 唯一「零服务器 + 国内直连 + CORS 齐全」自动档**；**PeerJS 云信令国内直连可用**（黑科技档首选）；
> **坚果云 WebDAV 无 CORS（实测不可行）**；**y-webrtc 公共信令已全部下线**；**Nostr 国内直连被 DNS 污染（需代理）**；
> **不上 CRDT**（Automerge 1.6MB gz 出局；FSRS 非可合并寄存器，改造 ≥1–2 周收益趋零）。

## 1. 选项矩阵（结论）

| 档 | 定位 | 结论 |
| --- | --- | --- |
| (f2) **GitHub Gist** | **P1 自动档默认** | CORS 全通 + 直连；secret gist **非私密** → 必须客户端 AES-GCM；单文件 <512KB 分片（API `truncated` 规避）；PAT `gists:write`/`gist` |
| (d) **Web Share 文件** | **P0 即上（发送侧）** | 改一行 `canShare({files}) → share({files})`；AirDrop/微信都能接；接收统一走「打开文件导入」 |
| (c) **PeerJS 云扫码直传** | **P2 黑科技首选** | 已验证国内直连；房间码/二维码配对 → DataChannel 分片（≤64KB/条）；跨网需国内 STUN（如 `stun.miwifi.com:3478`，Google STUN 国内超时） |
| (a) **Nostr** | P2 优雅增量（代理人群） | kind:30078 + NIP-44 + relay pool；**注意**：事件时间戳会被中继钳制，不能当同步时钟 |
| (e) **FSA 文件夹镜像** | P2 桌面实验 | 句柄持久化 + 重启后一次授权手势；移动端不做 |
| (b) CRDT / y-webrtc | ✗ 不做 | 论证见 §0/TL;DR |
| 动画二维码（air-gap） | P2 备选 | <300KB 增量 → 20–60 帧动画 QR，零网络最黑科技 |

## 2. 推荐架构（分层）

- **传输可插拔**：`SyncTransport { probe/pull/push }`；实现：`file → gist → (nostr|webrtc|folder)`。
- **合并层纯函数**：`mergeSync(input): MergeResult`——**HLC + 实体级 LWW + 删除墓碑 + 三方哈希**：
  - Book/Schema/ExportSettings/studyConfig/lookupSources：三方指纹（base/local/remote）；双改 → 冲突默认 remote（可翻转）；
  - Entry 主体：`(updatedAt, deviceId)` LWW；**applyReview 不写 updatedAt**，SRS 独立合并；
  - Entry.srs：仅一端复习 → 取该端；双端 → `lastReview` 晚者胜（平局 deviceId）；显式重置尊重；
  - study.daily：按日 **逐计数器 max**（幂等/可交换；不求和，避免重复计）；防"删了又回来"靠墓碑（180 天 TTL）；
  - settings 的 `lastBookId` 永久排除（每设备本地）。
- **加密与配对（与传输解耦）**：ECDH(X25519/P-256) → HKDF → AES-GCM-256(gzip(payload))；SAS 短语码防中间人；配对二维码载荷。
- **UI**：设置页「跨端同步」卡（导出/分享/导入同步包、配对、对账、状态徽标）；合并前自动安全快照×3。
- **节奏**：hydrate+5s / visibility（≥10min pull）/ 学习会话结束与批量导入后 30s push / online 即拉 / 可见时 30min 定时；`navigator.locks` 单飞 + BroadcastChannel 回流 rehydrate；失败退避 1m→5m→30m→2h。
- **黑科技选项**：气隙动画二维码；自建 Cloudflare Worker（KV 信箱 / WebDAV CORS 代理）——可选不默认。

## 3. 数据格式 v1 要点

- `SyncEnvelopeV1 { format:"wulonvocab-sync", version:1, kind, packId, deviceId, hlc, baseCursor, pairId, crypto:{alg:"none"|"AES-GCM"}, payload(base64 gzip), checksum }`
- `SyncPayloadV1 { mode:"snapshot"|"delta", since, books[{book, entries?}], tombstones[], settings?(去 lastBookId), lookupSources?, dictionaries? }`
- 分片：**32KB 明文/片**（适配最严格中继 128KB & Gist 512KB）；Gist 用 revision id 当天然游标。
- 版本策略：`format+version` 双闸门；新增字段一律可选；快照永远可解析；与备份格式（覆盖恢复）解耦。
- 规范草案（TS 接口）见研究原稿；实现目录：`src/lib/sync/{types,clock,merge,pack,envelope,meta,engine,auto,pair,crypto,transport,transports/*}`。
