# 导出与打印指南

导出工作室的每个设置都对应真实的印刷工艺参数。本指南解释「怎么选」以及「打印店怎么配合」。

## 1. 纸张怎么选

| 纸张 | 尺寸 (mm) | 适合 |
| --- | --- | --- |
| A4 | 210 × 297 | 家用打印机直接打；对折可装订成 A5 小册 |
| A5 | 148 × 210 | **随身词册首选**；A4 纸对折即两页 A5 |
| B5 (ISO) | 176 × 250 | 教材/教辅常用开本 |
| B5 (JIS) | 182 × 257 | 日本标准，部分打印店默认 |
| 16 开（正度） | 185 × 260 | 中国图书常见开本，交印刷店成书最自然 |
| 32 开（正度） | 130 × 184 | 口袋本；同尺寸 A4 一张可拼 4 页 |

> 注意：Chrome 打印对话框里的 "B5" 是 ISO 176×250；JIS B5 需选择「自定义」。16 开/32 开请用「自定义尺寸」。

## 2. 页边距与装订

| 预设 | 用途 |
| --- | --- |
| 舒适阅读 | 留白充足，A5/B5 推荐 |
| 标准 | 均衡 |
| 省纸紧凑 | 双面打印、草稿版 |
| 装订友好 | 内侧留 5mm + **双面镜像**；胶装 / 铁圈装订不压字 |
| 骑马钉 | 折页中缝留 3mm；页数建议为 4 的倍数 |

**双面打印**请在打印对话框选择「沿长边翻转」（flip on long edge），并开启「双面镜像」，
奇偶页的内外边距会自动互换。

## 3. 版式

- **流式分栏**：1 栏（笔记本式）/ 2 栏（仿纸本词典）/ 3 栏（速查表）。词条按内容高度自动分页，
  跨页的义项会带「（续）」标记并重复词性徽标。
- **网格闪卡**：每页固定 `行 × 列` 个词条，适合裁剪成卡片或自测；「闪卡精简模式」只显示头部与首个字段。
- **手账模式**：卡片底部加虚线手写行；把「隐藏空字段」关闭后，空字段留白，可打印成**手写填空词卡**。

## 4. 字体与纸色

- 无衬线（Geist + 系统中文字体）：屏幕感、清爽；
- 衬线（宋体系）：纸书感、长时间阅读友好；
- 米黄护眼纸色在打印时需要勾选「背景图形」才会印出色块（否则打印机自动省墨留白）。

## 5. 三种导出通道

### 矢量 PDF（推荐用于打印装订）
点击「打印 / 矢量 PDF」→ 浏览器打印窗口：

1. 目标：**另存为 PDF**（或直接选择打印机）；
2. 边距：**无 / None**（页面边距已在文档内计算，务必不要再叠加）；
3. 缩放：**100 / 默认**（不要"适合页面"，否则毫米尺寸会被改写）；
4. 选项：勾选 **背景图形 / Background graphics**；
5. 页眉页脚：关闭。

产物是矢量文字 PDF，可搜索、可选中，中文字体自动嵌入子集，打印店可直接拼版印刷。

### 一键图片 PDF
点击「一键图片 PDF」直接下载（默认 2.5× ≈ 240 DPI JPEG 内嵌）。零对话框、便于分享；
像素级所见即所得，但文字不可搜索、体积略大。

### PNG 图片
「PNG」菜单可选 192 / 300 / 384 DPI，多页打包为 ZIP。用于插图、电子手账、社交媒体分享。

DPI 对照（A5 单页）：

| pixelRatio | DPI | 像素（148×210mm） |
| --- | --- | --- |
| 2× | 192 | 1119 × 1587 |
| 3.125× | 300 | 1748 × 2480 |
| 4× | 384 | 2237 × 3175 |

## 6. 封面与索引

- 封面 4 种风格（极简居中 / 色带横幅 / 边框经典 / 打字机）；封面不编页码；
- 索引页按字母序或列表序生成，可 1–4 栏、带页码点线；页码与正文页脚一致；
- 页脚可显示「当前页 / 总页数」、自定义文字与词库名（左右两端）。

## 7. 交给打印店时说明

- 文件：矢量 PDF；页数、开本、单面/双面、装订方式（骑马钉 / 胶装 / 铁圈）；
- 如需裁切：作品四周已有安全边距，常规裁切不会切到内容；
- 骑马钉册子请按 4 的倍数补空白页（导出时可按需在词库尾部加一页装饰页或留白）。
