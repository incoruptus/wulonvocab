> **拍板记录（2026-11-17 · 学习线深化，依据新一轮调研 + 真实使用反馈）**：
> ① **新词闪卡＝三步式**：「有印象 / 没印象」二键**只路由不评分**；没印象→教学卡（不评分）；有印象→四选一验证，对记 **Hard**、错记 **Again** 并回教学卡；
>    「看词说义」成功才 **Good**，中→英产出成功才 **Easy**。初学显式短步骤（10–30 分钟 → 1 天 → 3 天），毕业交 FSRS。
>    依据：再认≠回忆（Laufer & Goldstein 2004）、能力错觉（Koriat & Bjork 2005）；直接映射 Good/Easy 会致首间隔虚长与 post-lapse 骤短。
> ② **词库「不学习」＝三态**：`Wordbook.studyState = active / paused / archived`（缺省 active）。暂停不计今日计划与目标分母，但**到期时钟继续走**，恢复靠既有每日上限自然分摊（**不批量改写 due**）；
>    归档默认隐藏、可逆、仍可浏览与自由练习。字段随书主体 LWW（`updatedAt` + deviceId），纳入合并/序列化/备份；队列层统一拦截。
> ③ **分组＝分区 + 学习批次分离**：浏览分区可按任意维度（标签 / 情景标签 / 首字母 / 状态 / 记忆强度桶 / 来源），可折叠、可存为视图，**本地偏好不同步、不复制词条**；
>    学习批次只允许主题 / 来源 / 频率 / 随机，**语义标签禁新词同批**（可用于复习辨析专项）。依据：Nation 2000 / Waring 1997 / Erten & Tekin 2008（语义集组有害初学）、Tinkham 1997（主题聚类优）、Brunmair & Richter 2019（词汇材料块状优，g=−0.39）。
> ④ **第一批＝秩序与口径**（排序扩维与持久化 + 浏览分区 + 词库三态 + 入口收敛），**先落文档、待龙明确说开做再动代码**（2026-11-24 已实施交付）；施工图见 `docs/PLAN-2026-11.md`。

## 已知限制（有意为之）

- 打印路径以 Chromium 系浏览器为最佳（Safari/Firefox 的 `@page` 行为略有差异）；
- 超大词库（>5 万条）的导出为内存敏感操作，建议分批导出或升级到 Web Worker 测量（见下）；
- 单条超长内容（超过整列高度）会被裁剪而非自动缩小；可用「紧凑」卡片样式缓解。
