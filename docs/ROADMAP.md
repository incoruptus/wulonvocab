## 已知限制（有意为之）

- 打印路径以 Chromium 系浏览器为最佳（Safari/Firefox 的 `@page` 行为略有差异）；
- 超大词库（>5 万条）的导出为内存敏感操作，建议分批导出或升级到 Web Worker 测量（见下）；
- 单条超长内容（超过整列高度）会被裁剪而非自动缩小；可用「紧凑」卡片样式缓解。
