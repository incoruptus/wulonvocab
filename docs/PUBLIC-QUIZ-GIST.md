# 配置 WulonVocab 公共选择题题库

这份指南把一个公开 Gist 配置成 WulonVocab 的匿名只读题库。应用不要求 GitHub Token，也不会把词库、学习记录或 API Key 上传到题库。

## 1. 先在应用里生成公共文件

1. 打开示例十词词库，进入工作区顶部的「题库」。
2. 点击「导入示例题」。示例词会得到 40 道个人题，每个词覆盖四个选择题子型。
3. 按需要增删或编辑个人题。保存时会检查四个选项、唯一答案、易混项差异说明，以及题目与词条义项是否一致。
4. 在「公共题署名」填写匿名或你的名字，选择 CC0-1.0 或 CC-BY-4.0。
5. 点击「一键生成公共题库」，下载 `wulonvocab-public-bank.json`。

生成文件只包含题目、审核状态、时间与署名，不包含 SRS、复习日志、词库字段、设备 ID 或凭据。发布前可以用文本编辑器打开文件，确认没有这些内容。

## 2. 创建公开 Gist

1. 登录 GitHub，打开 <https://gist.github.com/>。
2. 在 Description 中填写例如 `WulonVocab public question bank`。
3. 文件名必须填写为 `wulonvocab-public-bank.json`，注意不是 `.txt`。
4. 用文本编辑器打开刚下载的文件，全选并粘贴到 Gist 编辑框。
5. 选择 **Create public gist**。不要选择 Secret， Secret Gist 不适合作为公共匿名分发地址。
6. 创建后打开该 Gist，点击文件旁的 **Raw**。
7. 复制浏览器地址栏中的 Raw 地址。它应当以 `https://gist.githubusercontent.com/` 开头，打开后直接显示 JSON。应用会自动把带固定 revision 的 Raw 地址规范为最新文件地址，避免个别 revision 链接返回 404。

不要把 `gist.github.com/<user>/<id>` 的网页地址填进应用。应用需要的是 Raw 文件地址。如果 Raw 按钮给出的地址带有额外参数，先去掉参数再测试能否直接得到 JSON。

## 3. 在应用中启用

1. 回到词库工作区的「题库」。
2. 在「公共题库地址」粘贴 Raw 地址。
3. 点击「一键设置为公共题库」。应用只保存这个 HTTPS 地址，不保存 GitHub 凭据。
4. 选择题库分层：
   - **公共题库**：只读取公共层。
   - **个人题库**：只读取当前词库的个人题。
   - **两层（个人优先）**：先命中个人题；没有时再读取公共题。
5. 到「复习参数」把学习模式设为「选择题」或「混搭」，并启用需要的子型。新词库默认启用四个子型；旧词库若关闭了「看词选英文释义」，可点击「启用四子型」。
6. 开始一轮复习。命中公共题时，反馈区会显示公共题来源；没有命中时会按顺序使用内置编辑题、显式开启的 AI 与词条字段。新词首学验证固定为看词选中文释义，想验证公共 `word2def` 请对已学词复习或使用「自由练习这批」。

## 4. 更新题库

1. 在应用里修改个人题，再重新生成公共文件。
2. 打开原 Gist，不要另建一个，替换 `wulonvocab-public-bank.json` 的内容并保存。
3. Raw 地址保持不变，所有用户继续读取同一个地址。
4. 应用会缓存清单或分片 24 小时。更新后最早可能要等缓存过期，或在备份与恢复页清理可重建缓存，再开始新会话验证。

## 5. 排查读取失败

- 地址必须是 HTTPS，且直接返回 JSON。返回 GitHub 登录页、HTML 页面或 404 都无法读取。
- 单文件格式的顶层应包含 `format: "wulonvocab-public-quiz-bank"`、`schemaVersion: 1` 与 `questions` 数组。
- 每题必须通过本地准入校验。公共文件生成器会把个人题标记为 `approved`，但应用仍会重新检查。
- 一个网络地址短暂失败后，不同选择题子型会共享 30 秒冷却，避免连续等待多个超时。
- 只想验证读取，不必开启 AI。公共题库与个人题库都不需要 API Key。

## 6. 后续公共维护

当前 Gist 是匿名只读分发层。题目源文件、Issues、Pull Requests、审核记录与纠错流程适合放在单独的公共 GitHub 仓库；应用内直接上传仍需要后续 GitHub OAuth 与审核流程。消费端协同可视化题库编辑器属于长期方向，本指南不依赖它。
