# WulonVocab 项目结构与逻辑总览

> 整理日期：2026-11-25
> 状态：产品目标与当前实现对照。标为「目标」的内容尚未全部落地。
> 用途：作为产品、工程与「关于」页原理说明的单一真源。代码与已确认拍板优先于历史调研。

## 1. 产品结构

WulonVocab 是本地优先的个人英语词汇应用，核心链路是：

**建立词库 → 录入或导入词条 → 学习与复习 → 查看掌握证据 → 导出或打印。**

主要界面与职责：

| 区域 | 路由 | 核心职责 |
|---|---|---|
| 品牌首页 | `/` | 说明产品定位与主要入口 |
| 学习中心 | `/learn` | 汇总活跃词库、今日计划、目标与学习统计 |
| 学习会话 | `/study?id=` | 新词三步流、复习、题型、评级、回炉、撤销与小结 |
| 词库列表 | `/books` | 管理词库、三态与最近使用 |
| 词库工作区 | `/book?id=` | 词条编辑、字段设计、复习参数、选择题题库、筛选分区、保存视图、添加与导入 |
| 导出工作室 | `/book/export?id=` | 纸张、版面、主题、字段显示、分页预览与 PDF / PNG 导出 |
| 导入 | `/import` | JSON / CSV / NDJSON / Word / PDF / 图片等统一导入入口 |
| 设置 | `/settings/*` | 通用偏好、外观、数据源、词典、同步、备份与关于 |

### 1.1 词库工作区

当前代码已有四个 Tab：

- **词条编辑**：列表、筛选、分区、保存视图、词条表单与预览。
- **字段设计**：动态字段表、字段类型、显示选项与导出效果预览。
- **复习参数**：当前词库的每日新词与复习上限、保持率、题型、推进方式、自动发音、规划、顽固词阈值等。
- **题库**：公共只读题、个人可维护题、公共 / 个人 / 个人优先分层，以及个人题的新建、编辑、删除、导入、导出与公共文件生成。

按词库参数与学习首页快捷项共用同一个 `Wordbook.study.config`，不复制配置。旧 `/settings/study?book=<id>` 深链会跳到对应词库的复习参数页。个人题编辑器使用可聚焦的对话框，移动端满屏，避免入口在页面下方不可见。

### 1.2 设置信息架构

迁移后的分工：

- `/settings/study`：跨词库通用偏好，包括退出去向、直选键位、目标档位、连续学习、学习日界与公共题库地址。
- `/book?id=` 的「复习参数」：只影响当前词库的学习配置；「题库」分层管理公共只读题与个人可维护题。
- `/settings/appearance`：深浅模式、强调色与界面缩放。
- `/settings/sources`：在线词典、AI 与自定义 HTTP 数据源。
- `/settings/dictionaries`：本地词典元数据与下载数据。
- `/settings/sync`：同步包、Gist 自动同步、PeerJS 直传与合并预览。
- `/settings/data`：整库备份、恢复、复习日志与缓存清理。
- `/settings/about`：版本、作者、鸣谢、技术栈与原理手风琴。

## 2. 数据模型

### 2.1 核心实体

- `Wordbook`：词库，包含字段表、词条、导出设置、学习三态、学习配置与保存视图。
- `Entry`：词条，包含词头、标签、星标、动态字段值、来源、SRS 调度与顽固词搁置。
- `Schema`：动态字段定义，决定词条有哪些字段、字段类型与显示选项。
- `StudyConfig`：按词库存储的学习配置。
- `Wordbook.personalQuizBank`：按词库存储的个人选择题，使用稳定 ID、更新时间与删除墓碑。
- `BookStudy.daily`：按学习日聚合的统计，用于每日上限、目标与历史展示。
- `AppSettings`：跨词库的通用设置与设备本地设置。
- `LookupSourceConfig`：词典、AI 与自定义 HTTP 数据源配置；凭据已独立本机保管。
- `ExportPreset`：可跨词库复用的整套导出设置。
- `SavedView`：命名保存的筛选、排序、分组与折叠快照，属于词库用户数据。

### 2.2 存储与同步边界

| 数据 | 目标边界 | 说明 |
|---|---|---|
| 词库、词条、字段、导出设置、学习三态与学习配置 | 同步 | 用户内容与学习状态 |
| 命名保存视图 | 同步 | 随所属词库保存、合并与备份 |
| 当前排序、筛选、分区选择、折叠态 | 本机 | 设备上的临时工作状态，不是保存视图 |
| 复习事件与撤销补偿 | 同步 | 用于跨设备保持弱词证据与掌握层次；采用稳定事件 ID、确定性去重与滚动保留 |
| 通用设置 | 同步 | 排除外观与明确的设备界面状态 |
| 数据源非凭据配置 | 同步 | 地址、模型、字段映射等跟随 |
| API Key、Authorization 等凭据 | 仅本机 | 不同步、不进入备份；换机后重新填写 |
| 深浅模式、强调色、最近使用词库 | 本机 | 外观与最近使用状态；界面缩放与侧栏状态随通用设置同步 |
| 设备身份、配对码、GitHub Token、游标、墓碑与安全快照 | 仅本机 | 墓碑按既有规则单独随载荷传播，其余元数据不传播 |
| AI 管家聊天记录 | 本机 | 个人对话资产 |
| 检索、Cloze、Word Quiz 生成缓存 | 本机 | 可重建缓存，不进入主同步 |
| 本地词典行数据 | 本机 | 只同步词典元数据，避免巨大载荷 |
| 公共题库下载缓存 | 本机 | 按需更新，离线可复用 |
| 待上传的公共题贡献包与本地举报记录 | 同步 | 属于用户产生的内容，不应因换机丢失 |

保存视图与复习事件已进入同步；API Key 与自定义请求头已迁入独立本机凭据库；按词库复习参数、题库工作区与关于页手风琴均已实现。公共题贡献待发件与举报记录尚未进入同步，这是明确的实现差距，不是产品原则。

## 3. 同步逻辑

### 3.1 目标原则

龙于 2026-11-25 明确：

- 能体现用户学习状态、词库管理的数据都要同步。
- 已保存视图也要同步。
- 其余边界由实现方按数据语义管理。

据此，同步只排除三类内容：凭据、外观与设备状态、可重建缓存及大型外部数据。个人产生的学习证据、保存视图和待贡献题目不因存储位置而默认排除。

### 3.2 复习日志同步规则

目标采用「原始事件同步，界面只读派生」，当前已实现：

- 每个事件有稳定 ID，跨设备按 ID 去重。
- 撤销继续写补偿事件，不删除原事件。
- 合并后按 `(ts, id)` 确定性排序，再应用统一的滚动保留窗口。
- 初始保留最近 180 天且最多 5,000 个有效事件；自由练习同样保留，但继续标注 `practiceOnly`。
- 掌握层次、弱词信号与统计全部由同一份有效事件派生，不另存一套可能漂移的摘要。
- 清空日志属于用户明确操作；普通缓存清理不得清掉学习证据。

这套规则保证换机后学习证据连续，同时限制载荷增长。Gist 既有分片机制负责传输，不提高 460KB 阈值。

### 3.3 当前同步载荷与差距

当前 `buildSyncPayload` 发送：

- 词库主体：名称、描述、标签、字段表、导出设置、学习三态、学习配置、每日统计与命名保存视图。
- 词条：内容、标签、星标、状态、SRS、搁置、来源与时间戳。
- 设置：当前排除 `theme`、`accent`、`lastBookId`。
- 数据源：只发送非凭据配置；API Key 与自定义请求头仅在本机请求发出前注入。
- 本地词典元数据，不包含词典行数据。
- 导出预设。
- 删除墓碑。
- 复习事件：稳定 ID、撤销补偿与清空标记，按 180 天 / 5,000 条滚动保留。

尚未进入同步：公共题贡献待发件与本地举报记录。当前临时视图偏好继续留本机。

### 3.4 合并规则

- 单边修改取修改方。
- 双边修改同一处时，按时间戳与设备 ID 裁决，冲突可在预览中翻转。
- 词条主体使用 `(updatedAt, deviceId)` 的最后写入胜出规则。
- SRS 独立合并，优先采用较晚的复习结果，并尊重显式重置。
- 保存视图使用稳定 ID，按 `(updatedAt, deviceId)` 合并；删除写词库级墓碑。
- 复习事件按 ID 去重，补偿事件通过引用撤销原事件，不使用时间戳猜撤销关系。
- 每日统计逐计数器取较大值，避免重复累计。
- 删除通过墓碑传播，防止旧设备把删除项复活。
- 合并前在本机保留最近三份安全快照。

### 3.5 同步方式

- 同步包：导出一个文件，在另一台设备导入并预览合并。
- Gist 自动同步：配对码派生密钥，内容加密后上传到用户自己的 GitHub Gist。
- PeerJS 直传：同一会话码用于信令房间与加密密钥，数据通过 WebRTC 直传。

公共 Word Quiz 题库与个人同步是两条独立链路：个人同步始终加密，公共题库只包含用户主动发布的题目。

### 3.6 自动触发点

- 启动后约 5 秒。
- 切回前台且距上次同步超过 10 分钟。
- 恢复联网。
- 应用常驻时每 30 分钟。
- 学习会话开始与结束。
- 设置、学习参数、保存视图、数据源、导入与导出预设等离散改动。
- 手动点击「立即同步」。

## 4. 学习逻辑

### 4.1 新词与复习是两条路径

- 新词：从未建立 SRS 的词，走三步初学流程。
- 复习：已经建立 SRS 的词，按到期时间与记忆强度进入队列。
- 自由练习：暂停或归档词库也可进入，不改 SRS 与每日统计。目标口径下，练习事件仍作为学习证据同步，并明确标注 `practiceOnly`。

### 4.2 新词三步流

1. **教学卡**：展示词形、音标、释义、例句与可选搭配，不评分。
2. **熟悉感路由**：选择「有印象 / 没印象」，只决定下一步，不直接评分。
3. **验证或回忆**：
   - 有印象：先做限时四选一再认验证，正确记 Hard，错误记 Again 并回教学卡。
   - 没印象：回教学卡，之后进入看词说义的回忆自评。
   - 回忆成功记 Good，费力记 Hard，答不出记 Again 并揭晓答案。

新词 Good 的短步骤为：**30 分钟 → 1 天 → 3 天 → FSRS**。FSRS 提前返回 Review 时，只要初始学习步尚未完成，就保留 Learning 状态。

### 4.3 复习调度

- 使用 FSRS-6，核心参数封装在 `src/lib/study/engine.ts`。
- 评级为 Again / Hard / Good / Easy。
- 忘记后在本轮持续回炉，不设静默次数上限。
- 用户可按 X 显式「先放下」，记 Again 但本轮不再回炉。
- 预览与评分共享同一个 `now`，避免间隔预览与实际评分不一致。
- 复习排序可选到期优先或最可能忘的优先。
- 相似词避让是软约束，不阻塞、不丢词。

### 4.4 三大题型与 Word Quiz 四子型

用户最终选择三个大类：

| 大类 | 用户可见名称 | 作用 |
|---|---|---|
| 熟悉度自评 | 熟悉度自评 | 教学卡后的回忆自评与翻卡评级 |
| Word Quiz B1 | 选择题 | 限时四选一，测再认与线索回忆 |
| Cloze | Cloze | 从真实或经校验的例句中提取目标词；拼写作为其产出性子型保留 |

Word Quiz B1 合并现有三种选择题，并增加英英释义题，共四个子型：

| 子型 | 题面 | 选项 |
|---|---|---|
| `word2def` | 英文词形与音标 | 四个英文释义 |
| `def2word` | 一句英文释义 | 四个英文词 |
| `zh2word` | 一个中文义项 | 四个英文词 |
| `word2zh` | 英文词形与音标 | 四个中文释义 |

统一规则：

- 每题四个选项，1 个正确答案、1–2 个真正易混项，其余为对照项。
- 四个子型分别可配置 10 / 15 / 20 / 25 / 30 秒；默认 `word2def` 30 秒、`def2word` 20 秒、`zh2word` 与 `word2zh` 各 15 秒。页面隐藏或打开弹层时暂停。
- 旧版统一 10 / 25 秒会迁移到全部子型；旧默认 15 秒采用新的分档默认值。已有子型配置优先。
- 超时记 Again，必须停留并揭示答案。
- 正确最高 Good；开启「稳 / 猜」时猜对记 Hard。
- 隐藏词头的 `def2word` 与 `zh2word` 作答前不显示目标词、不朗读。
- AI 或题库不可用时按可用题型降级，全不可用回退翻卡。
- 旧稿「一句正确句 + 三句 AI 错句」不是 Word Quiz B1，已撤回。

B2 的来源想法是给句填空。当前产品使用 **Cloze** 这个独立名称，不再把它称为 Word Quiz B2。

学习模式有四个选项：熟悉度自评、选择题、Cloze、混搭。前三种独立使用；混搭通过 `quizMixWeights` 调整三大类相对占比，通过 `choiceMixWeights` 调整四个选择题子型占比。调度使用确定性的平滑加权轮转，保留当前阶段的可用题型；新词三步验证不参与混搭。Cloze 缺例句时回退自评，不偷偷改成选择题。独立 Cloze 模式稳定期可选用拼写，混搭不额外插入拼写。详细规范见 [`research/word-quiz-definitions-2026-11.md`](./research/word-quiz-definitions-2026-11.md)。

### 4.5 规则档规划

- 先安排到期复习，再安排新词。
- 时间不足时先减少新词，不删除积压，也不修改到期时间。
- 考试日期前两周进一步压缩新词。
- 弱词优先只重排当前复习候选，最多占 20%，不直接改变评分。
- 学习批次只允许随机、主题或情景标签、来源、频率，新词批次为 5–10 词。

### 4.6 目标、连续学习与顽固词

- 每日有效提取目标有三档：20 / 40 / 60。
- 可显示连续学习天数，每周自动宽恕一次漏学日。
- 学习日界默认凌晨 4 点，可配置 0–6 点。
- 顽固词达到阈值后可搁置 7 / 30 天、跳到编辑或确认后降级重学。
- 搁置不改 SRS 与到期时间，到期后自动回归。

### 4.7 R(30) 与掌握证据

- R(30) 是按当前记忆强度估计的 30 天后可提取性，不是永久掌握。
- 再认 / 回忆 / 产出由复习日志派生。
- 同一词、同一会话、同一层只取首次有效评分，每层最多保留最近 20 次。
- 这些证据不写回 SRS，也不改变 `EntryStatus`。
- 原始复习事件已跨设备同步并统一派生；掌握层次只读这份事件集，不另存同步摘要。

## 5. 公共 Word Quiz 题库

### 5.1 目标

公共题库让人看到某词是否已有题，并支持社区上传、举报与纠错。题目通常需要 AI 生成自然英文释义与真正的易混词；已有释义不等于已有合格选项。

### 5.2 架构决策

- **公共 GitHub 仓库**：维护题目源文件、Issues、Pull Requests、举报与审核记录。
- **公共 Gist**：作为匿名只读分发镜像，由 Actions 在审核后生成清单与分片。
- **应用**：匿名按需拉取单词所在分片，本地缓存并再次校验；单文件公共题库可直接作为 Gist Raw 地址读取。
- **个人题库**：保存在 `Wordbook.personalQuizBank`，按稳定 ID 随词库合并并支持删除墓碑。工作区「题库」页支持新建、编辑、删除、导入示例、导出与生成公共文件；每个词库可选择公共、个人或个人优先的两层并用。
- **内置编辑题**：示例十词覆盖四个子型共 40 题；没有题库命中时作为离线编辑题供给，也可导入个人题库继续修改。
- **公共文件生成**：个人题可一键生成带审核状态与所选署名的单文件公共题库，只含题目，不带学习数据或凭据。
- **贡献**：用户预览题目后生成标准化贡献包；获得明确授权后才发送到 GitHub。
- **隐私**：贡献包只含题目与署名，不含词库、学习日志、设备 ID、API Key 或个人笔记。

未完成 OAuth Application 注册与公共仓库创建前，应用先实现只读题库和贡献包下载，不提供伪装成可用的上传按钮。公共 Gist 的手工配置步骤见 [`PUBLIC-QUIZ-GIST.md`](./PUBLIC-QUIZ-GIST.md)。

## 6. 字段、导入与导出逻辑

### 6.1 动态字段

- 词条内容存储在 `Entry.values`，字段结构存储在 `Schema.sections`。
- 字段类型包括文本、列表、标签、音标、义项、例句、键值、词形、表格、图片、引用、评分与分隔线。
- 字段重命名会迁移现有数据。
- 删除字段不丢数据，数据进入「未定义字段」，可以再次提升。

### 6.2 导入

- 所有入口最终汇入统一导入管线。
- 管线负责识别、归一化、字段推断、去重与冲突预览。
- 词库内「添加并匹配」用于单条添加，整批导入仍走独立导入页。
- 重复导入保持幂等。

### 6.3 导出

- 导出设置与词库内容解耦。
- 预览、测量与打印共享同一套布局参数。
- 支持 A4 / A5 / B5 / 16 开 / 32 开、多栏、封面、索引、页脚与四套主题。
- 输出矢量 PDF、图片 PDF 或 PNG ZIP。
- 「跟随列表排序」当前读取设备本地临时偏好；保存视图同步后，跨设备导出可显式选择某个已保存视图，避免依赖另一台设备的临时状态。
